## 2. ПОЛНЫЙ USER JOURNEY MAP

### Сценарий A: «Жертва мошенника» (основной)
```
1. Пользователь получает подозрительный звонок
2. Гуглит номер → попадает на ScammerKetKz
3. Вводит номер в поиск на главной
4. → Найден: видит репорты, компанию, описание, уровень риска
   → Не найден: видит "Запись не обнаружена" + CTA "Сообщить о номере"
5. Голосует (нужен логин) → или регистрируется
6. Добавляет свой репорт (если есть новая инфа)
7. Делится ссылкой в соцсетях
8. Возвращается позже → проверяет рейтинг, комментарии
```

### Сценарий B: «Активный борец» (геймификация)
```
1. Регистрируется (Google / Telegram / телефон)
2. Добавляет репорты → получает очки
3. Голосует за чужие репорты → получает очки
4. Оставляет комментарии → получает очки
5. Поднимается в рейтинге → получает статус
6. Делиться своими достижениями
7. Раз в неделю проверяет leaderboard
```

### Сценарий C: «Бизнес-клиент» (B2B монетизация)
```
1. Приходит через поиск или рекламу
2. Попадает на /business → видит презентацию API
3. Регистрируется → получает API ключ (100 req/day free)
4. Тестирует через документацию
5. Превышает лимит → видит тарифы → оплачивает
6. Интегрирует в свой продукт
```

### Сценарий D: «Telegram пользователь»
```
1. Находит бота → /start
2. /check номер → результат
3. /add → пошаговое добавление
4. /top → топ компаний
5. Открывает Mini App → полный функционал сайта
```

### Сценарий E: «Случайный посетитель»
```
1. Попадает на главную
2. Видит статистику (X записей, Y компаний)
3. Пробует поиск → находит что-то интересное
4. Листает топ компаний
5. Переходит в базу репортов
6. Возможно регистрируется
```

## 4. MONETIZATION STRATEGY (психологически выверенная)

### Принцип: "Полезность > Реклама"
Пользователь не должен чувствовать, что на нём зарабатывают.
Монетизация встроена в ценность, а не накинута сверху.

### 4.1 B2B API (основной доход)
- **Free tier**: 100 запросов/день (для малого бизнеса)
- **Pro tier**: $49/мес — 10,000 запросов/день
- **Enterprise**: $299/мес — безлимит + SLA + webhook
- Целевые клиенты: банки, маркетплейсы, службы доставки, страховые
- Landing: /business с реальным кодом и документацией

### 4.2 Нативная реклама (ненавязчивая)
- **Не больше 2 рекламных блоков** на страницу
- Формат: "Полезный сервис" (банки, антивирусы, VPN)
- Позиции: 
  - После результатов поиска (когда пользователь уже получил ценность)
  - В sidebar базы репортов (не в главной зоне)
- Стиль: вписано в дизайн (paper/ink), не кричащее
- Никаких pop-under, interstitial, auto-play

### 4.3 Партнёрские программы (affiliate)
- Kaspi/Halyk — реферальные ссылки на безопасные продукты
- Антивирусы — партнёрка
- VPN сервисы — партнёрка
- Формат: "Рекомендуем для защиты" в результатах поиска

### 4.4 Data licensing
- Агрегированные данные для исследовательских организаций
- Отчёты для СМИ (тренды мошенничества)
- API для государственных органов

### 4.5 Donations (ненавязчиво)
- Кнопка "Поддержать проект" в футере
- Telegram Stars / Boosty
- НЕ в основном флоу, НЕ модалка

## 5. UX/UI ПЕРЕРАБОТКА

### 5.1 Главная страница
- **Hero**: Усиленный CTA, социальное доказательство (счётчики)
- **Виджет "Проверь прямо сейчас"**: мгновенный поиск без скролла
- **Живая лента**: последние добавленные репорты (как твиттер)
- **Топ-5 компаний**: с количеством жалоб и трендом
- **Социальное доказательство**: "X пользователей онлайн"
- **Trust badges**: "Защищено", "Проверено сообществом"

### 5.2 Результаты поиска
- **Цветовая индикация риска**: зелёный/жёлтый/красный
- **Быстрые действия**: "Тоже звонили" (без комментария, 1 клик)
- **Похожие номера**: если найден, показать связанные
- **Share кнопки**: Telegram, WhatsApp, копировать ссылку

### 5.3 Форма репорта
- **Пошаговый wizard** (не одна большая форма)
- Шаг 1: Номер → Шаг 2: Кто звонил → Шаг 3: Детали → Шаг 4: Подтверждение
- **Прогресс-бар** с анимацией
- **Автодополнение компании**: начать вводить "Kaspi" → подсказка
- **Загрузка файлов**: реально реализовать (Cloudinary/free tier)

### 5.4 Профиль
- **Карточка достижений**: бейджи, ранг, прогресс
- **История активности**: таймлайн
- **Сохранённые поиски**: уведомления о новых репортах
- **Статистика**: сколько помог людям (эмоциональная привязка)

### 5.5 Leaderboard
- **Топ-3 на подиуме** с анимацией
- **Фильтры**: неделя/месяц/всё время/по регионам
- **Профиль по клику**: достижения, статистика
- **Сезонные награды**: "Борец декабря"
