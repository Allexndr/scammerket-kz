# ScammerKetKz - Платформа против мошенничества в Казахстане

## 🌟 О проекте

ScammerKetKz - это краудсорсинг-платформа для борьбы с мошенничеством в Казахстане. Пользователи могут:
- Сообщать о подозрительных звонках и мошенниках
- Проверять номера телефонов и компании
- Голосовать за достоверность информации
- Просматривать аналитику и рейтинги

## 🚀 Особенности

### ✅ Реализованные функции:
- **Поиск по номеру телефона или компании**
- **Форма отчетов о мошенниках**
- **Система голосования (лайки/дизлайки)**
- **Рейтинг пользователей с геймификацией**
- **Аналитика и статистика**
- **API для экспорта данных**
- **Telegram бот для быстрого доступа**
- **Полная интернационализация (русский/казахский/английский)**
- **Адаптивный дизайн для всех устройств**
- **Полное E2E тестирование**

### 🎯 Геймификация:
- **Ранги**: Новичок → Охотник → Эксперт → Мастер
- **Очки** за отчеты и голосования
- **Лидерборд** активных участников

## 🚀 Развертывание

### Vercel (рекомендуется):
1. Подключите репозиторий к Vercel
2. Добавьте переменные окружения:
   ```
   MONGODB_URI=ваша_строка_подключения_mongodb
   TELEGRAM_BOT_TOKEN=токен_бота (опционально)
   ```
3. Разверните проект

### Локальная разработка:
```bash
# Установите зависимости
npm install

# Запустите базу данных MongoDB
# Добавьте переменные окружения в .env.local

# Запустите dev сервер
npm run dev

# Откройте http://localhost:3000
```

## 📊 API

### Основные эндпоинты:
- `GET /api/scams` - список отчетов
- `POST /api/scams` - создать отчет
- `POST /api/scams/[id]/vote` - голосование
- `GET /api/analytics/top-companies` - топ компаний
- `GET /api/leaderboard` - рейтинг пользователей
- `GET /api/export` - экспорт данных

## 🤖 Telegram бот

Для быстрого доступа к платформе:
```
/start - запуск бота
/check <номер> - проверка номера
/add - добавление отчета
/top - топ компаний
/myrating - личный рейтинг
```
